# 天災降臨

一款上帝視角的網頁小遊戲：從空中俯瞰一座城市，選擇天災、點擊城市，把來來去去的人和車子一網打盡！

## 玩法

1. 開頭選擇模式：**所多瑪・限時**／**所多瑪・人口爆炸**／**現代・限時**／**現代・人口爆炸**
   - 限時：所多瑪 90 秒、現代 60 秒，比分數
   - 人口爆炸：人越生越快，城裡超過 150 個人車就輸
2. 從畫面下方選一種天災（電腦可按數字鍵 1～4）
3. 點擊城市降下天災

現代城市的天災（背景音樂：A 小調電子節奏）：

| 天災 | 效果 | 冷卻 |
|---|---|---|
| ⚡ 閃電 | 瞬間命中、範圍小 | 無冷卻 |
| ☄️ 隕石 | 延遲約 1 秒落下、超大範圍 | 3.5 秒 |
| 🌪️ 龍捲風 | 自己移動 5 秒，把沿路的人車捲走 | 6 秒 |
| 👻 惡靈附身 | 點一個人讓他發狂追殺別人，殺滿 5 人自爆 | 5 秒 |

計分：人類 +10、機車 +15、汽車 +20、計程車 +25、公車 +50；一次擊中 3 個以上，每個再加 10 分（天火的整陣火雨合計算一次連殺）。

### 📜 所多瑪（限時 90 秒／人口爆炸）

致敬《創世記》所多瑪的故事，場景改為早期迦南／黎凡特地區的青銅時代城市（泥磚屋、梯形巨塔、綠洲、城牆），配上即時合成的荒涼背景音樂。

| 天災 | 效果 | 冷卻 |
|---|---|---|
| 🧂 鹽柱 | 範圍內的人與馬車化為鹽柱 | 無冷卻 |
| 🔥 天火 | 大範圍降下約 37 顆硫磺火球，熔岩填滿整個範圍約 6 秒，持續燒灼 | 4.5 秒 |
| 👁️ 忌邪之眼 | 移動的視線，罪人陷入瘋狂、加速衝向身邊的人攻擊（瘋狂者彼此不會互打），殺 3 人或數秒後自爆 | 6 秒 |
| 😇 天使救援 | 點擊發白光的「義人」，天使把他接走（+300） | 1.2 秒 |

- 義人約每 12～17 秒出現一位，頭上有倒數圈；救援時限從 12 秒開始，每位縮短 1.5 秒，最低 5 秒
- 太晚救援或用天災誤傷義人：-300
- 義人剛出現時有 2.5 秒無敵護盾

## 新手教學

這台裝置的瀏覽器裡，如果還沒有所多瑪（或現代）的任何分數紀錄，第一次進入該主題時會先跑一段新手教學，可隨時按 **SKIP** 跳過。教學結束後會重新開一局正式遊戲。

## 沒有聲音？

- 瀏覽器規定網頁要等玩家點擊後才能出聲，第一次點擊之後才會有音效
- iPhone：若仍沒有聲音，請確認手機側邊的靜音開關沒有打開，並把音量調大
- 右上角 🔊／🔇 是遊戲內的靜音開關

## 放上 GitHub Pages

1. 到 GitHub 這個 repository 的 **Settings → Pages**
2. 「Source」選 **Deploy from a branch**
3. 「Branch」選放有 `index.html` 的分支、資料夾選 `/ (root)`，按 Save
4. 等 1～2 分鐘，頁面上方會出現網址，分享給朋友就能玩

## 想調整難度？

打開 `index.html`，搜尋「設定值」，可以改：
- `TIME_LIMIT`：限時模式秒數
- `POP_LIMIT`：人口爆炸模式的上限
- `POP_GROWTH`：人口爆炸模式的人口成長速度
- `COMBO_PER`：連殺時每個目標多加的分數
- `GHOST_KILLS`：惡靈殺幾人後自爆
- `DIS` 裡的 `cd`（冷卻秒數）和 `r`（攻擊範圍）
- `SODOM_TIME`、`RESCUE_SCORE`、`DIS_S`：所多瑪模式的時間、救援分數與天災數值
